# Memex Development Guidelines & Agent Rules

## Primary Language Directive
- **English-Only Policy**: All code, documentation, rustdoc comments, commits, pull requests, issue descriptions, and agent-generated artifacts must be written in **English**.

## Code Quality & Standards
- Run `cargo fmt` to adhere to formatting standards.
- Run `cargo clippy --all-targets -- -D warnings` to verify lints.
- Run `cargo test` to execute unit and integration test suites.
